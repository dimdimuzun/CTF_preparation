# check-ctf-tools.sh

Bash-скрипт для перевірки наявності інструментів, необхідних команді для CTF-змагання. Перевіряє все, що згадано у двох шпаргалках команди:

- `ctf-cheatsheet.md` — хід Linux-пентесту (recon, web, SMB, паролі, RCE, reverse shell, привілеї, кодування)
- `ctf-crypto-forensics-pwn.md` — Crypto, Forensics, Pwn

## Що робить скрипт

Проходить по списку з ~65 пунктів і для кожного перевіряє, чи інструмент доступний у системі. Результат — таблиця-чекбокс (`[x]` / `[ ]`) по кожному пункту, згрупована за розділами, що повторюють структуру шпаргалок. Наприкінці — додаток з інструкціями встановлення, але **лише для того, чого не вистачає** (не для всього списку).

Скрипт нічого не встановлює сам і нічого не змінює в системі — лише читає, перевіряє наявність і виводить звіт.

## Вимоги

- Bash (стандартний у будь-якому дистрибутиві на базі Debian, зокрема Parrot і Kali)
- Python 3 — потрібен лише для перевірки Python-бібліотек (`pycryptodome`, `base58`, `pwntools`); якщо його немає взагалі, ці три пункти просто позначаться як відсутні, решта скрипта відпрацює нормально

Інших залежностей немає.

## Запуск

```sh
chmod +x check-ctf-tools.sh
./check-ctf-tools.sh
```

Щоб зберегти звіт у файл (наприклад, щоб переслати тренеру чи порівняти результати різних ноутбуків команди):

```sh
./check-ctf-tools.sh | tee ctf-tools-report.txt
```

## Типи перевірок

Для кожного пункту скрипт використовує один із чотирьох способів перевірки:

| Тип | Як перевіряє | Приклад |
|---|---|---|
| `cmd` | Чи є команда в `$PATH` (`command -v`) | `nmap`, `gobuster`, `hydra` |
| `file` | Чи існує конкретний файл за вказаним шляхом | `rockyou.txt`, `linpeas.sh` |
| `dir` | Чи існує директорія і чи вона не порожня | `GTFOBins`, `RsaCtfTool` (клоновані репозиторії) |
| `py` | Чи імпортується Python-бібліотека (`python3 -c "import X"`) | `pycryptodome`, `base58`, `pwntools` |

## Налаштування шляхів

На початку скрипта є блок змінних для інструментів, які зазвичай ставляться вручну (git clone, завантаження файлу), а не через `apt`. За замовчуванням скрипт шукає їх у `~/tools/...` — якщо у вас інша структура директорій, підправте значення перед запуском:

```sh
ROCKYOU_PATH="/usr/share/wordlists/rockyou.txt"
GTFOBINS_DIR="$HOME/tools/gtfobins"
RSACTFTOOL_DIR="$HOME/tools/RsaCtfTool"
LINPEAS_PATH="$HOME/tools/linpeas.sh"
CYBERCHEF_DIR="$HOME/tools/CyberChef"
PHP_SHELL_PATH="$HOME/tools/php-reverse-shell.php"
PWNDBG_DIR="$HOME/pwndbg"
```

Ці самі значення можна передати й без редагування файлу, через змінні середовища при запуску:

```sh
GTFOBINS_DIR=/opt/gtfobins ./check-ctf-tools.sh
```

## Розділи перевірки

Скрипт перевіряє інструменти в такому порядку (відповідає розділам шпаргалок):

1. Розвідка та веброзвідка (`netdiscover`, `nmap`, `gobuster`, `dirb`, `dirsearch`, `wpscan`, `searchsploit`)
2. SMB-розвідка (`enum4linux`, `smbclient`)
3. Паролі та брутфорс (`fcrackzip`, `john`, `zip2john`, `hashid`, `hashcat`, `hydra`, `medusa`)
4. Знайдені файли й креди (`gpg`, `mysql`, `mysqldump`)
5. RCE / SQLi (`sqlmap`, `msfvenom`)
6. Reverse shell і перенесення файлів (`nc`, `curl`, `wget`, `ssh`/`scp`, `python3`)
7. Підвищення привілеїв (`getcap`, `strings`, `gcc`, `perl`, `vim`, `ftp`, `locate`)
8. Кодування та стеганографія (`stegcracker`, `steghide`, `binwalk`, `zsteg`, `xxd`)
9. Офлайн-ресурси (`git`, GTFOBins, rockyou.txt, linpeas.sh, php-reverse-shell.php, CyberChef)
10. Crypto (`openssl`, RsaCtfTool, `pycryptodome`, `base58`)
11. Forensics (`exiftool`, `foremost`, `scalpel`, `mmls`, `volatility`, `wireshark`, `tshark`, `pdf-parser`, `oletools`)
12. Pwn (`checksec`, `gdb`, `objdump`, `ltrace`, `strace`, `file`, `pwntools`, `pwndbg`/`GEF`)

## Відомі обмеження

- Деякі інструменти можуть бути встановлені під іншою назвою команди, ніж та, що шукає скрипт (наприклад, якщо `volatility3` поставлено вручну зі своєю обгорткою) — у такому разі скрипт покаже "відсутній", хоча фактично інструмент є. У сумнівних випадках перевірте вручну через `which <назва>`.
- Скрипт перевіряє лише **наявність**, не версію і не працездатність інструменту.
- Не виконує жодних перевірок в мережі (не телефонує нікуди) — працює повністю офлайн.

## Для кого

Призначений для запуску на кожному ноутбуці команди окремо перед тренуваннями чи змаганням — щоб заздалегідь побачити, чого не вистачає, а не виявляти це на самому змаганні.
